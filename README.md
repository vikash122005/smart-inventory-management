**Smart Inventory Management System**

**Problem:**
        Small retail stores often manage inventory and sales using Excel, making it difficult to identify low-stock products, fast-moving products and products that may require reordering.

**Objective:**
        The system will ingest historical sales and inventory data from Excel/CSV files, validate and transform the data, store it in PostgreSQL and provide analytics through a Streamlit dashboard.
        
        It will also allow users to record new sales and automatically update inventory(Which will become the realtime inventory management).

**V1 Scope:**
        This project has been divided into separate versions. Starting with V1
        ✓ Historical sales data ingestion
        ✓ Data validation
        ✓ Data cleaning/transformation
        ✓ PostgreSQL database
        ✓ Basic inventory analytics
        ✓ Basic Streamlit dashboard
        ✓ Record a sale
        ✓ Automatically decrease stock
        ✓ Low-stock status
